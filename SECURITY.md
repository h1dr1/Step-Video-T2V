# Security Policy

## Reporting a Vulnerability
If you discover a security vulnerability, please report it by sending an email to security@example.com. All security reports will be reviewed and addressed promptly.

## Security Guidelines
- Keep software up to date.
- Use strong passwords and 2FA wherever possible.
- Regularly review your code for vulnerabilities.

## Support
For further information and support, please refer to our documentation or reach out to our team.
